# cpc-hub-mirror

Зеркало загрузок **CPC Hub** — лаунчера портов CPC Art Studio. Здесь лежат только подписанные пакеты релизов
(релиз `live`), которые хаб скачивает сам: без исходного кода и без данных с дисков игр. Образы дисков игрок
подключает свои.

- Telegram-канал студии: https://t.me/CPC_Art_Studio
- Условия для моддеров: [Parasite Eve](MODDING_TERMS_PE1.md) · [Parasite Eve II](MODDING_TERMS_PE2.md)
